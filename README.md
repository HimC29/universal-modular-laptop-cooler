# The Universal Modular Laptop Cooler
**Designed by: Him C. <himc.29z@gmail.com>**

## The Problem with Regular Laptop Coolers
Most laptop cooling pads have fans fixed in one permanent spot. However, every laptop model has its intake vents in different locations. For example, my Asus VivoBook only has a vent in one top corner. Standard coolers do not line up with it, making them inefficient.

## My Solution
A universal, modular laptop stand that can be adjusted to fit **any** laptop perfectly.
The system consists of three main components:
- **The Grid Platform:** A main, elevated stand featuring a grid of screw holes accross the surface (similar to a pegboard).
- **Fan Blocks:** Moveable sqaures of different sizes housing a 5V 1A fan with foam on top. These can be screwed in anywhere on the grid to align perfectly with your laptop's vents, creating an airtight seal.
- **Passive Support Blocks:** Matching solid squares of different sizes topped with rubber padding. These bolt onto the rest of the grid to keep the laptop perfectly flat, level, and stable so it never tips over.

## Project Specifications
- **Power Supply:** Safe 5V USB power (can run off a standard 5V 3A mobile phone charger block).
- **Speed Control:** Uses a low-voltage potentiometer/PWM controller knob to adjust fan speeds and optimize airflow pressure.
